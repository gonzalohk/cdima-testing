# Variables de Entorno

Este proyecto utiliza variables de entorno para configurar el token de Asana y otras configuraciones sensibles.

## Configuración Inicial

1. **Copia el archivo de ejemplo:**
   ```bash
   cp .env.example .env
   ```

2. **Obtén tu token de Asana:**
   - Ve a https://app.asana.com/0/my-apps
   - Crea un token de acceso personal
   - Copia el token generado

3. **Configura el archivo .env:**
   - Abre el archivo `.env`
   - Reemplaza `tu_token_de_asana_aqui` con tu token real
   - Ejemplo:
     ```env
     VITE_ASANA_TOKEN=1/1234567890abcdef:1234567890abcdef
     ```

4. **Reinicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

## Variables Disponibles

### Obligatorias

- `VITE_ASANA_TOKEN`: Token de acceso personal de Asana

### Opcionales

- `VITE_ASANA_WORKSPACE_ID`: ID del workspace de Asana (para preconfiguración)
- `VITE_ASANA_PROJECT_ID`: ID del proyecto de Asana (para preconfiguración)
- `VITE_API_URL`: URL de API personalizada (si aplica)

## Notas Importantes

- ⚠️ **NUNCA** subas el archivo `.env` al repositorio
- El archivo `.env` está incluido en `.gitignore` por seguridad
- El archivo `.env.example` sirve como plantilla sin datos sensibles
- En Vite, las variables de entorno deben tener el prefijo `VITE_` para estar disponibles en el cliente
- Los cambios en `.env` requieren reiniciar el servidor de desarrollo

## Prioridad de Tokens

El sistema utiliza el siguiente orden de prioridad:

1. Token guardado en localStorage (cuando el usuario lo configura en la UI)
2. Token desde el archivo `.env` (como fallback)
3. Error si no hay ningún token disponible

Esto permite que puedas:
- Usar un token por defecto desde `.env`
- Cambiar el token temporalmente desde la interfaz
- El token de la interfaz tiene prioridad sobre el de `.env`

## Solución de Problemas

Si el token no funciona:

1. Verifica que el archivo `.env` está en la raíz del proyecto
2. Asegúrate de que la variable comienza con `VITE_`
3. Reinicia el servidor de desarrollo
4. Limpia el localStorage del navegador si es necesario
5. Verifica que el token es válido en Asana
